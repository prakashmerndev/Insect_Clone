# Insect_Clone
HTML & CSS Clone Project

This is a frontend clone project created using HTML and CSS.

The main purpose of this project was to practice and understand how website layouts can be created using basic CSS positioning techniques.

🚀 Technologies Used
HTML5
CSS3
🎯 CSS Properties Used

In this project, I mainly used only:

display: flex
position

I created the complete layout using these two CSS properties to improve my understanding of Flexbox and Positioning.

📌 Features
Beginner-friendly HTML & CSS
Clone of an existing website/design
Layout created using display: flex
Elements positioned using position
No responsive design
Simple and clean code structure
📚 What I Learned

While building this project, I practiced:

Creating website structure with HTML
Using Flexbox for layout
Positioning elements with CSS
Understanding how different elements interact with each other
Recreating an existing website design from scratch
💻 Project Purpose

This project is part of my journey to improve my frontend development skills and strengthen my understanding of CSS layout techniques.
